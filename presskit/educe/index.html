Description

Educe is a pixel-art metroidvania built without a game engine. The runtime is hand-written C-like C++ compiled directly to WebAssembly via LLVM (no Emscripten), rendering through WebGPU and orchestrated from a tiny JavaScript host. The whole game ships in kilobytes.

Features

  • Pixel-art metroidvania with hand-tuned exploration and combat.
  • Custom engine: C++ → WASM via LLVM, no Emscripten runtime.
  • WebGPU rendering pipeline written from scratch.
  • Build size measured in KB — loads in a tab, runs natively on Steam.

History

Engine first, game second

Educe started as an experiment in shrinking a game runtime as small as it can go: writing a C++ codebase that compiles straight to WebAssembly with LLVM's WASM backend, skipping Emscripten and its runtime entirely, and rendering through the browser's native WebGPU. The metroidvania grew up around that engine.

From browser to Steam

What began as a web-only project shipped on Steam (app 4486530) wrapped as a desktop build, while the same core continues to run in any modern browser.

About Educed Moment

Educed Moment is an independent game studio founded by Tristen MacPherson. We build small, focused games with a deep interest in the craft underneath: writing engines from scratch, treating performance as a feature, and shipping things that fit in a browser tab. More information on the studio.
