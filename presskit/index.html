Description

Educed Moment is an independent game studio founded by Tristen MacPherson, a solo developer based in Saskatoon, Canada. The studio is currently building Educe, a photography metroidbrainia, on a custom C/C++ tech stack — alongside Tristen’s internship at Winterpixel Games and a master’s in games research.

The studio’s focus is small, handcrafted games where every system — engine, audio synth, asset pipeline, photo gallery format — is built deliberately to serve the work.

Educe

Educe is the studio’s first commercial title — a photography metroidbrainia where players creep through flooded caverns, photograph wildlife, and recreate compositions from empty frames embedded in the world. In development since July 2025. Currently first playable, with builds for Windows, macOS, iPad, and Web.
