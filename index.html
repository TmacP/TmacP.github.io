Educe

Available on Steam

A pixel-art metroidvania built without a game engine. Custom C++ → WebAssembly via LLVM (no Emscripten), WebGPU rendering, build sizes measured in kilobytes. Runs in a browser tab. Ships on Steam.

About

Educed Moment is an independent game studio founded by Tristen MacPherson. We have a deep interest in the craft underneath games — writing engines from scratch, treating performance as a feature, and shipping things that load in a tab.
